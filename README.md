# RetailIQ – Sales Performance & Business Intelligence Dashboard

## Project Overview

Developed an interactive Retail Analytics Dashboard using Microsoft Power BI to analyze sales performance, revenue trends, customer activity, cancellations, and product performance.

## Objectives

- Integrate multiple retail datasets into a unified data model.
- Perform data cleaning and transformation using Power Query.
- Develop relationships using Star Schema data modelling.
- Create calculated columns and DAX measures.
- Build interactive dashboards for business decision-making.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- CSV Data Sources
- Data Modelling

## Dataset Description

1. CityTier – City classification and market tiers.
2. PinCode-Geo – Pincode, city and geographical zones.
3. Product Mapping – Product categorization.
4. Sales Transactions – Revenue, units, cancellations and customer information.

## Key KPIs

- Total Revenue
- Net Units Sold
- Cancellation Rate
- Unique Customers
- Total Transactions
- Average Revenue per Transaction
- Week-on-Week Revenue Growth

## Key Features

- Revenue Performance Analysis
- Cancellation & Loss Analysis
- Customer & Demand Trends
- Product Performance Analysis
- Executive Management Dashboard
- Interactive Filters and Slicers
